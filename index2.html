PanelForge
PanelForge is a desktop-first web application for designing, previewing, and simulating AIDA64 SensorPanel layouts without running AIDA64 or owning target hardware.

It provides a pixel-perfect canvas, a rich widget system, and a built-in sensor simulation engine, allowing users to design complex panels entirely in the browser and export them as images or JSON configurations.
